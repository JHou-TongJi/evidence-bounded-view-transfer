# 目标小车传感器说明

## 1. 目标车型与设定依据

本项目的目标车型定义为 **L4 低速无人配送车**，面向园区、校园、住宅区、物流园和城市末端配送道路等低速运行场景。车辆尺寸与载荷能力参考 [Neolix X3 公开产品资料](https://www.neolix.cn/productTechnology)，并结合本试验的跨车型视角重建需求，构建 `neolix_x3_size_7v_v1` 工程化目标 rig。

该 rig 用于定义目标传感器的空间布局和输出视角；相机内外参是面向虚拟重建实验的工程参数，不代表任何厂商的 OEM 标定。

| 项目 | 设定 |
|---|---|
| 车辆类型 | L4 低速无人配送车 |
| 车身长度 | 2.69 m |
| 车身宽度 | 1.08 m |
| 车身高度 | 1.82 m（不含顶部 LiDAR） |
| 轴距 | 1.73 m |
| 货厢容积 | 3.0 m³ |
| 参考载荷 | 520 kg |
| 设计最高速度 | 50 km/h |
| 典型运行场景 | 园区、校园、住宅区、物流园、城市末端配送道路 |
| 传感器拓扑 | 7 路环视 RGB 相机 + 1 路车顶 LiDAR 元数据 |

## 2. 坐标系定义

目标车辆采用车体坐标系 `ego`：

```text
+x：车辆前方
+y：车辆左侧
+z：车辆上方
```

`ego` 原点定义为假设后轴中点在地面的投影位置。目标相机采用 OpenCV 相机坐标系：

```
+x：图像右方
+y：图像下方
+z：镜头前方
```

目标相机到车体的刚体变换记为：

$$
\Large p_{ego} = T_{camera\_rig} · p_{camera}
$$

其中 $T_{camera\_rig}$ 将相机坐标中的点转换到目标车辆 `ego` 坐标。目标车辆在世界坐标中的轨迹与源 NCore 采集车在相同时刻的 rig pose 对齐：

$$
\Large T_{camera\_world}(t) = T_{rig\_world}(t) · T_{camera\_rig}
$$

渲染器使用其逆矩阵作为 OpenCV world-to-camera view matrix。这样，虚拟配送小车沿用源车在道路中的行驶轨迹，同时使用目标小车的相机安装位置、朝向与成像参数生成新视角。

## 3. 目标相机成像模型

全部 7 路目标相机均采用统一的校正 pinhole 模型，用于生成无畸变 RGB 输出。

| 项目         | 参数                                                         |
| ------------ | ------------------------------------------------------------ |
| 相机数量     | 7                                                            |
| 输出分辨率   | 1920 × 1080                                                  |
| 输出帧率     | 30 FPS                                                       |
| 水平视场角   | 100°                                                         |
| 垂直视场角   | 67.673°                                                      |
| 焦距         | `fx = fy = 805.5356 px`                                      |
| 主点         | `cx = 959.5 px`, `cy = 539.5 px`                             |
| 快门建模     | global-shutter midpoint proxy                                |
| 原始镜头参考 | 参考 [Leopard Imaging LI-IMX390-GMSL2 广角相机资料](https://leopardimaging.com/wp-content/uploads/2023/12/LI-IMX390-GMSL2-xxxH_Datasheet_V1.4.pdf) 的车规广角相机能力范围 |

本试验输出的是校正后的 pinhole 图像，便于不同目标视角之间统一投影与渲染。它不模拟真实镜头畸变、曝光、ISP、运动模糊或 rolling shutter。

## 5. 与源乘用车传感器的关系

目标相机安装高度为 1.62–1.72 m。以本试验的源前广角相机为例，其 NCore 标定中的安装高度约为 1.61 m；目标前中相机高度为 1.72 m，前侧相机也分布在更贴近配送小车车身边界的位置。

因此，本项目并非仅改变图像朝向，而是同时改变：

- 相机相对车辆前后、左右边界的位置；
- 相机安装高度；
- 前、侧、后环视覆盖关系；
- 目标相机的 pinhole 内参与 100° 视场；
- 输出图像分辨率与相机阵列组织方式。

这些变化共同构成从乘用车采集 rig 到低速无人配送车 7V rig 的跨车型视角迁移。
