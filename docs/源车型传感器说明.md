# 源车型传感器说明

## 1. 源数据概述

本项目的源数据来自 NVIDIA 发布的 [PhysicalAI Autonomous Vehicles NCore 数据集](https://huggingface.co/datasets/nvidia/PhysicalAI-Autonomous-Vehicles-NCore)。当前实验使用 clip：

```text
7fd4d554-b155-45c6-a46a-646486029d85
```

源端为乘用车/自动驾驶采集车传感器 rig。数据包含道路场景的多相机 RGB、相机标定、曝光时间、车辆世界位姿、顶置 LiDAR、动态 cuboid track 等信息，可用于构建跨车型的新视角渲染任务。

## 2. 源端传感器组成

| 传感器类型         | 典型设备/数据内容                             | 在本项目中的作用                                   |
| ------------------ | --------------------------------------------- | -------------------------------------------------- |
| 7 路道路相机       | FTheta RGB 图像、内参、安装外参、曝光起止时间 | 静态场景训练、天空构建、动态目标监督与原视角验证   |
| 顶置 LiDAR         | `lidar_top_360fov` 稀疏点云                   | 道路表面尺度约束、深度审计、动态目标可观测性分析   |
| 车辆 pose graph    | `T_rig_world(t)`                              | 将源相机、LiDAR、目标小车 rig 对齐到统一世界坐标   |
| cuboid track       | 车辆、作业设备、行人等目标的时空包围盒        | 动态实例筛选、actor 监督与时间窗定义               |
| 动态实例/语义 mask | 原始 mask 与保守传播 mask                     | 静态训练时排除动态 RGB，构造动态目标监督与留出评估 |

## 3. 源相机视角与成像模型

当前 NCore clip 使用多路道路相机提供前向、前长焦、左右交叉、后向及后长焦等覆盖。与本试验直接相关的相机 ID 包括：

| 源相机 ID                   | 名称所示视场 | 主要用途                     |
| --------------------------- | ------------ | ---------------------------- |
| `camera_front_wide_120fov`  | 120°         | 前向道路主视角、时间参考相机 |
| `camera_front_tele_30fov`   | 30°          | 前向远距离细节               |
| `camera_cross_left_120fov`  | 120°         | 左侧交叉视角                 |
| `camera_cross_right_120fov` | 120°         | 右侧交叉视角                 |
| `camera_rear_left_70fov`    | 70°          | 左后覆盖                     |
| `camera_rear_right_70fov`   | 70°          | 右后覆盖                     |
| `camera_rear_tele_30fov`    | 30°          | 后向远距离细节               |

源相机使用 NCore 标定定义的 FTheta 成像模型。该模型保存像素距离与入射角之间的多项式关系、主点、最大可视角度以及线性校正参数，因此不能简单等价为普通 pinhole 相机。

对于 `camera_front_wide_120fov`，本项目已直接读取 NCore 原始标定并用于精确原视角验证：

| 项目           | 参数说明                                                     |
| -------------- | ------------------------------------------------------------ |
| 原始图像分辨率 | 1920 × 1080                                                  |
| 相机模型       | NCore FTheta                                                 |
| 标称视场       | 120°                                                         |
| 快门类型       | `ROLLING_TOP_TO_BOTTOM`                                      |
| 安装位置示例   | `(2.010, -0.061, 1.610) m`，相对源车 rig                     |
| 曝光位姿       | 使用每帧 START / END 时间分别求取 rig pose                   |
| 原视角验证     | 按逐扫描行位姿计算 FTheta 射线，并与导出的静态 Gaussian 场景对齐 |

## 4. 源坐标系与变换关系

NCore 中的变换采用 `T_source_target` 命名，表示将 source 坐标中的点转换到 target 坐标。对于任一源相机：

$$
\Large p_{rig}   = T_{camera\_rig} · p_{camera} \\
\Large p_{world} = T_{rig\_world}(t) · p_{rig}
$$

因此：

$$
\Large T_{camera\_world}(t) = T_{rig\_world}(t) · T_{camera\_rig}
$$

其中：

- `camera`：源相机 OpenCV 坐标系，`+x` 向右、`+y` 向下、`+z` 向前；
- `rig`：源采集车坐标系；
- `world`：NCore 全局道路场景坐标系；
- `T_camera_rig`：源相机安装外参；
- `T_rig_world(t)`：源采集车在时刻 `t` 的世界 pose。

源 LiDAR 使用车辆坐标约定：

```
+x：车辆前方
+y：车辆左侧
+z：车辆上方
```

LiDAR 点先通过相应时间的车辆 pose 转到 `world`，再通过目标相机的 world-to-camera 变换投影至目标视图。

## 5. 源相机与目标小车相机的差异

| 对比项         | 源乘用车采集 rig                        | 目标 L4 小车 rig                             |
| -------------- | --------------------------------------- | -------------------------------------------- |
| 车辆类型       | 乘用车/自动驾驶采集车                   | 低速 L4 无人配送车                           |
| 相机模型       | 原始 FTheta，部分相机带 rolling shutter | 校正 pinhole、global-shutter midpoint proxy  |
| 前向主相机视场 | 120° FTheta 广角                        | 100° pinhole 广角                            |
| 主相机安装高度 | 前广角约 1.61 m                         | 前中相机 1.72 m                              |
| 相机布局       | 面向源车道路采集的前、交叉、后向组合    | 前中、前左右、左右侧、后左右的 7V 环视布局   |
| 输出分辨率     | 由 NCore 各源相机原始标定定义           | 统一输出 1920 × 1080                         |
| 轨迹           | 源车真实采集轨迹                        | 沿用同一世界轨迹，以目标相机外参重新观测场景 |

在实际流程中，源端 FTheta 与 rolling-shutter 标定用于读取原始观测、构建天空和监督静态/动态重建；最终 L4 7V 图像由目标小车 pinhole 相机参数对重建场景直接光栅化得到。

## 6. 使用边界

源数据中的相机、LiDAR 与轨迹为跨车型重建提供了真实道路观测和几何约束，但源端并不包含目标配送小车的实采图像。因此，目标 7V 序列体现的是基于统一世界坐标、源端多模态观测和目标 rig 定义生成的虚拟视角结果。对于目标车辆真实镜头畸变、曝光、ISP、传感器噪声与动态目标完整性，仍需结合实车标定或额外验证数据进一步评估。
