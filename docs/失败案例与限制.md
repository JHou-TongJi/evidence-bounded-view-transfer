# 失败案例与使用限制

## 1. 文档目的与判定原则

本 final 保留可见失败，不使用生成式补洞、插帧或后处理把未知区域伪装为真实观测。以下分析以最终单路 1080p、7V mosaic、道路 LiDAR holdout、actor 来源时间留出及历史 A/B 实验为依据。

需要区分三种“通过”：

- **链路通过**：程序能完成训练/渲染，输出格式正确且无 NaN；不代表画质通过。
- **代理指标通过**：在明确的来源相机、LiDAR 有效像素或合成安全域内达标；不自动外推到目标 L4 新视角。
- **目标视角真实性通过**：需要目标 rig 的独立实采或等价高可信真值；本项目尚不具备该证据。

因此，最终结果只能描述为“完成 L4 7V 工程重渲染并通过分层代理检查”，不能描述为“恢复了真实动态 7V 世界”。

## 2. 近场车辆的涂抹、拉伸与静态泄漏

### 可见现象

近侧作业车、停靠车辆和遮挡边界会出现厚片、重复轮廓、拉伸纹理、边缘发亮或“车辆固定在背景上”的现象。该问题在前右、侧右和后向视角更明显，在源/目标对比图右列可直接观察：

![源乘用车与目标 L4 同时刻对比；右列近车显示明显的新视角外观缺失](src/source_vehicle_vs_target_l4_frame270.png)

### 原因

静态 2DGS 虽以动态 mask 排除对应 RGB loss，但初始几何和多时刻重建中仍可能吸收动态物体或其周边背景。目标相机与来源相机存在较大平移、转角和近场视差，单视角刚性 actor 又没有未观测侧面、背面及真实遮挡信息；直接提高到 1920×1080 只增加采样密度，不增加表面证据。

### 已验证但未奏效的修复

| 尝试 | 结果与结论 |
|---|---|
| clean-static v3 + exact-FTheta actor | 67 帧 ROI 改善 31.79%、全图改善 2.07%，但 temporal-delta 恶化 19.98%，未通过序列验收 |
| multi-camera clean-static v4 | 动态遮罩覆盖和静态/动态分离结构改善，但 static ROI MAE 变差；旧 actor 接入新背景也退化 |
| static expected-depth 硬遮挡 | static 本身含动态泄漏，会把 actor 错拒为灰洞；final 未启用该硬 gate |
| side-right 单相机近车 expert | 来源时间留出可过，但目标侧只覆盖 7 帧并产生亮块、厚边和错误视差，未进入 registry |
| 1080p 直接重渲染 | 边缘采样更细，但近车表面缺失不变，不能作为几何提升证据 |

### 改进方向

先取得至少两路有效对象观测或目标车小规模实采，再训练显式 occupancy/visibility、unknown surface、view-dependent appearance 和 depth ordering 的对象层。禁止继续依赖单目纹理、放宽 mask/LiDAR gate、单纯增加 iteration 或用生成式补色掩盖表面缺失。

## 3. 刚性动态 actor 的跨视角与时序不完整

### 可见现象

只有 4 个 track 的 6 个刚性 expert 进入 registry。目标在不符合来源方向、距离或时间窗时会回退静态背景，可能形成车辆忽隐、边缘厚薄变化、进入/离开瞬间 alpha IoU 降低，或未覆盖车辆保持为静态残影。

最终统计中，侧左、后左和后右的相邻 alpha IoU P05 为 0；后右均值仅 0.479380。这里既包含正常视锥进出，也包含来源覆盖不足和 gate 切换，所以不能把均值较高的相机解释为动态几何正确，也不能把 P05 为 0 单独解释为渲染崩溃。

### 原因

来源时间留出只验证 expert 在原相机的保留时刻。方向≤25°、距离比 0.60–1.60 和来源时间窗可以拒绝明显外推，却不能生成没见过的车身表面，也不能证明目标相机中的遮挡排序和外观正确。

### 历史证据

- InstantNuRec dynamic NPZ 在代表帧的动态改变区 MAE 改善 43.9%，但全图仅改善 1.68%、时序仅改善 0.30%；最近时刻或 actor-nearest 选择在多帧上不稳定。
- exact-FTheta canonical actor 的 67 帧时序 residual 恶化 30.65%；只学习 pose correction 后反而恶化 35.77%。
- Street Gaussians v7 的四帧精确 MAE 为 0.06893，仍差于同帧 static 0.06094，且 actor/static alpha 大范围重叠。
- source-anchor 在目标 L4 frame 15 的前中 raw/dense 覆盖仅 0.272%/0.247%，右侧最多 4.191%，证明 source mask/LiDAR 无法直接补出完整新视角车辆。

### 改进方向

把“actor 是否存在、哪一表面可见、谁在前方、哪些区域未知”作为显式可学习/可审计状态；目标侧验收至少包含跨物理相机时间留出、轮廓 IoU、面积比、可见深度排序和连续窗口 temporal residual。现有 registry 可继续作为 fail-closed 基线，但不应继续扩大角度或距离阈值来追求活跃帧数量。

## 4. 行人和可形变目标未恢复

### 可见现象

行人可能被静态背景稀释、模糊、不连续或完全缺失。不得从输出 RGB 推断可靠的人体轨迹、姿态、尺寸、朝向或遮挡关系。

### 原因与已做工作

行人不是刚性 canonical actor。项目已完成原生 FTheta/rolling 的多人物数据 bundle、逐轨采样和 smoke，但 rigid actor registry 明确排除 deformable person。EmerNeRF 的车辆 v2 短窗虽有正信号，后续更长窗 v3 为负；v5 的 visible-alpha IoU 仅 0.1015，未达到先行车辆 gate，因此没有启动人员正式 pilot，更没有将人员写入 final。

### 改进方向

使用时变/形变表示、实例级可见性和跨相机 silhouette/depth 排序监督；在车辆对象层先通过同一严格 holdout 后，再开展人员实验。禁止把 SAM2-only mask 当真实几何或把人物按刚体优化。

## 5. 侧向、后向、天空与低覆盖区域

### 可见现象

侧向和后向画面在源视图遮挡、近场边缘、树线及天空交界处会出现模糊、不透明低质量 surface、黑块、亮色补洞或低纹理区域。Mosaic 中间和底部中央的两个整块黑格只是 3×3 版式占位；相机 tile 内部的黑色/灰色/模糊区域则是实际输出，应视为低可信或未知。

### 原因

20-tile、5 相机上下文提高了环向覆盖，但没有消除跨时刻动态污染和未观测表面。Temporal sky 只有 18 个时间 slot，且只在 `1-alpha` 后方合成；它不能覆盖错误高 alpha 的树线、车辆或建筑。道路 LiDAR 又是稀疏监督，最终 holdout P90 仍为 1.997339 m，说明尾部几何误差不可忽略。

### 已验证边界

- 11-tile multi-scan 12k 的 holdout MAE/P90 为 1.10098/2.00667 m；20-tile final 为 1.06787/1.99734 m，主要改善是近场覆盖，不是全方向无误差。
- 20-tile 相对早期版本降低了黑色放射条带，但 low-alpha 和 sky-valid 回填比例上升，局部会出现亮色模糊洞。
- Depth Anything V2 的 LiDAR 锚定弱先验只带来约 3.1% 的道路 MAE 小幅改善候选，近侧动态涂抹不变，因此未替换 final 12k 模型。
- 路面 curvature 约束仅使 MAE 改善 0.23%，未达到重渲 7V 的收益门槛。

### 改进方向

增加真实侧后向静态观测和近场 LiDAR 覆盖，重建时显式输出 uncertainty/invalid mask；对 cubemap 增加可靠覆盖审计和接缝优化，但仍只允许填透明天空。不得用天空或 RGB 传播覆盖高 alpha 错误几何。

## 6. 对应、mask 与稀疏 LiDAR 的可观测性上限

### 实测限制

- 保守 raw RGB-LiDAR densification 仅新增 1 个 Gaussian，surface observed 为 2.81%、unknown 为 97.19%；放宽门槛只会把背景点吸入车辆。
- RoMa 在前向短基线和 1.345 m 横向基线两组原生 FTheta/rolling 三角化审计中 accepted 均为 0；候选射线虽然有角度，但 closest-distance 和 cuboid 约束不成立。
- SAM2 可增加时序 mask 覆盖，但 cross-view audit 显示部分新增 mask 被 static depth 遮挡或没有独立相机支持。它只能作为监督 sidecar，不能直接写 actor 或生成 target 图像。
- raw LiDAR 对象层说明“已观察面”可被验证，但 cuboid surface-probe 覆盖仅 8.57%，不足以重建完整车辆。

### 改进方向

需要专门的多视图动态对应/重建模型或新增真实观测，而不是继续降低三角化、LiDAR 3D gate 或多视图支持门槛。未知表面应保持透明并随输出携带置信度。

## 7. 成像模型和目标 rig 假设

源 NCore 相机为 FTheta，并具有 rolling-shutter 曝光首尾位姿；最终 L4 输出为 rectified pinhole/global-shutter midpoint proxy。项目没有模拟真实目标镜头畸变、运动模糊、曝光控制、色彩响应、噪声、压缩链或 ISP。

目标 7V 外参和车辆尺寸是 X3 尺寸级工程假设，不是 Neolix 或其他厂商的 OEM 标定。即使场景几何正确，输出也不能替代实车原始相机流。后续一旦取得目标车真实内外参和成像模型，应替换 rig JSON，并重新做覆盖、道路 LiDAR、时间同步、目标视角和传感器域验收。

## 8. 指标解释限制

| 指标 | 能说明 | 不能说明 |
|---|---|---|
| 视频帧数/分辨率/FPS | 输出协议和批处理完整 | 画面正确、同步误差为零 |
| 道路 LiDAR MAE/median/P90 | LiDAR 有效道路像素上的米制尺度误差 | 7V 全像素深度、车辆/人员几何 |
| 来源 masked RGB MAE | 来源相机保留帧内的纹理误差 | 目标 L4 新视角外观 |
| 来源 alpha IoU/面积比 | 来源视图轮廓膨胀或收缩 | 遮挡背面、目标视角轮廓 |
| actor 外 RGB MAE | 合成器未明显污染 actor 外静态 RGB | actor 本身正确、背景本身正确 |
| 相邻 alpha IoU | 轮廓连续性代理 | 动态真值、物体身份和三维运动正确 |

主观“看起来更清楚”不能替代上述分域指标，1080p 也不能被表述为新增几何证据。目标视角没有逐像素实采真值，是当前评价的根本边界。

## 9. 禁止用途与允许用途

### 禁止用途

- 自动驾驶安全认证、道路合规测试和碰撞距离测量；
- 动态对象/行人真值标注、轨迹真值和遮挡真值；
- 直接作为感知训练地面真值或驾驶策略闭环训练数据；
- 宣称为某 OEM 车型的真实标定、真实传感器流或实车采集；
- 用生成式补洞、画面锐化或插帧后的派生视频重新定义为训练真值。

### 允许用途

- 跨车型相机布局与 7V 同步视频的工程 demo；
- 静态场景、道路尺度和 target rig 覆盖的可视化；
- 渲染/编码/批处理接口联调；
- 后续显式 visibility、view-dependent appearance、deformation 和 uncertainty 动态架构的安全基线。

最终判断：当前流程“可以接入并完成目标 L4 小车 7V 视角重渲染”，但只在静态世界、协议完整性和保守局部刚性增强层面成立；完整动态真实性、目标传感器真实性和安全关键可用性均未通过。
