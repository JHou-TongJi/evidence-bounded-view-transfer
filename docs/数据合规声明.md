# 数据合规说明

## 1. 数据许可与使用前提

本项目的原始道路数据来自 NVIDIA 的 [PhysicalAI-Autonomous-Vehicles-NCore](https://huggingface.co/datasets/nvidia/PhysicalAI-Autonomous-Vehicles-NCore) 数据集。该数据集并非无条件开放下载：访问文件前，使用者需登录 Hugging Face 并接受 **NVIDIA Autonomous Vehicle Dataset License Agreement**。

数据集卡将许可标记为：

```text
nvidia-av-dataset
```

使用该数据前，应由具备相应授权的个人或机构确认已接受并遵守该协议。项目不以本说明替代原始许可文本；发生冲突时，以 NVIDIA 数据集页面及许可协议的最新版本为准。

## 2. 许可相关的关键约束

根据数据集卡中公开的 NVIDIA Autonomous Vehicle Dataset License Agreement，本项目应特别遵守以下要求：

1. 数据集的下载、使用、修改和复制应限定在许可协议明确允许的自动驾驶相关研发目的内。
2. 数据集页面公开可见，但数据文件受访问协议约束；不得将其视为可自由再分发的开放数据。
3. 不得出售、出租、再许可、转让、托管或向第三方提供全部或部分原始数据集。
4. 不得尝试识别、去匿名化或画像化数据中的个人、车辆牌照或其他可识别对象。
5. 不得开展人脸识别、生物特征处理、身份识别、情绪识别、社会评分或基于行人行为的个体追踪。
6. 不得将数据用于违法监控、执法用途或其他违反适用法律法规的用途。
7. 应记录原始数据及其副本的存储位置，并在许可终止、数据更新要求或删除通知时按协议执行。
8. 原始数据、部分派生结果、性能基准或竞争分析结果是否可对外披露，应按许可中的保密与分发条款以及赛事组织方的授权范围处理。

### 3. 数据隔离与最小化提交措施

为降低原始道路采集数据、标注信息及模型资产的外泄风险，本项目遵循“授权环境内处理、最小必要导出、提交包不含可还原原始数据”的原则。

| 数据类别                                    | 是否进入最终提交包 | 隔离与处理方式                                               |
| ------------------------------------------- | ------------------ | ------------------------------------------------------------ |
| 原始多相机图像、LiDAR、标定、轨迹与场景标签 | 否                 | 仅在具备数据集授权的本地计算环境中读取和处理，不复制至提交材料，不对外公开分发。 |
| NCore 数据索引、序列描述与中间数据格式      | 否                 | 仅用于本地加载、时间同步、相机位姿解析和训练/渲染流程，不作为提交内容提供。 |
| 预训练模型权重                              | 否                 | 仅在本地推理或训练中使用；最终提交不携带模型参数，并分别遵守对应模型的许可条款。 |
| 重建模型、中间 checkpoint 与高斯场景资产    | 否                 | 作为本地实验资产保存，用于复现实验流程；提交材料仅保留必要的配置说明、版本信息与结果指标。 |

最终提交包面向赛事评审与技术展示，仅包含必要的工程说明、可复现实验配置、评价结果、代表性图像及演示视频。原始采集数据、传感器标定与标签、完整帧序列、模型权重及外部项目代码均保持在授权环境内管理。

## 4. 派生视频与代表帧的披露边界

最终提交中的 7V MP4、同步 mosaic 和代表帧属于基于 NCore 观测生成的派生视觉结果。其披露范围应限定在赛事评审、项目验收或经许可授权的内部研发环境中。

在未获得 NVIDIA 数据许可和赛事组织方明确允许前，不应：

- 将最终 MP4、代表帧、完整渲染 PNG 或其可逆高质量版本公开上传至开放网站；
- 将派生图像作为独立数据集重新发布；
- 以原始数据或真实目标车辆采集数据的名义进行传播；
- 从画面中提取、传播或分析车牌、人脸、行人身份及其他可识别信息；
- 将视频用于人员追踪、行为画像、执法或监控用途。

如赛事规则要求公开展示，应优先使用赛事组织方批准的展示渠道、分辨率和访问权限，并在展示材料中保留数据来源与使用边界说明。

## 6. 隐私与脱敏要求

本项目不进行以下处理：

- 人脸识别、人体身份识别或生物特征提取；
- 车牌识别、车辆唯一标识追踪；
- 基于行人姿态、轨迹或行为的个人画像；
- 通过多帧关联推断特定个人或车辆的身份；
- 对敏感属性进行推断、分类或标注。

在人工检查视频、截取代表帧、编写失败案例和制作公开材料时，应避免突出、放大或重新标注可能识别个人或车辆的信息。若发现原始数据或派生结果存在未充分匿名化风险，应停止扩散、向数据提供方报告，并按适用许可和组织要求处理。

## 7. 最终结果的真实性与安全边界

本项目输出的是基于源车辆多模态观测和目标 L4 rig 定义生成的虚拟视角序列。它适用于跨车型视角重建、场景可视化和方法验证，不应被描述为：

- 目标 L4 小车的真实实采传感器数据；
- 自动驾驶安全认证、道路合规或碰撞责任判定依据；
- 动态对象轨迹、行人行为或车辆状态的地面真值；
- 可直接用于身份、行为或敏感属性分析的数据源。

任何后续使用均应在原始数据许可、第三方组件许可、赛事规则、适用数据保护法律和机构内部审批范围内进行。
