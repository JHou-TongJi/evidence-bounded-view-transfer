# 实测结果报告：1080p L4 小车 7V 视角重渲染

## 报告结论

本次 final 已完成从同一段乘用车 NCore 道路采集到工程定义 L4 小车 7V rig 的完整重渲染：7 路视频均为直接光栅化的 1920×1080 RGB，30 FPS、299 帧、9.966667 s，共对应 2,093 张最终 PNG，完整率 100%。结果通过了文件与视频一致性检查、同源静态 2DGS 的独立道路 LiDAR 检查、刚性 actor 来源相机时间留出筛选，以及最终 1080p actor 外背景保持检查。

本结果是跨车型多视角重建 demo 和后续模型研究基线。目标 rig 为 X3 尺寸级工程假设而非 OEM 标定，且目标新视角没有逐像素真值；因此报告不以主观观感、目标视角 RGB MAE 或 actor alpha 代替新视角真实性证明。

## 3. 方法与模型说明

### 3.1 目标小车视角与坐标转换

目标为 Neolix X3 尺寸级低速配送车的研究型 7V rig，而非 OEM 标定。七台相机均为 1920×1080、100° 水平 FOV 的 rectified pinhole，相机高度约 1.62–1.72 m，覆盖前中、前左、前右、左侧、右侧、左后和右后。

目标 ego 坐标为右手系：`+x` 向前、`+y` 向左、`+z` 向上；相机采用 OpenCV 坐标：`+x` 向右、`+y` 向下、`+z` 向前。NCore 的 `T_source_target` 表示将 source 点变换至 target，故目标相机位姿按下式组合：

$$
\Large T_{camera\_world}(t) = T_{rig\_world}(t) @ T_{camera\_rig} \\
\Large view\_matrix(t)    = inverse(T_{camera\_world}(t))
$$

虚拟 L4 小车沿用源采集车每个时刻的 world 轨迹，只把乘用车传感器安装布局替换为目标 7V rig。相机完整内外参见 `../03_工程代码/configs/7fd4_neolix_x3_size_7v.json`。

### 3.2 最终生成流程

```text
NCore 7V RGB / 标定 / rolling pose / LiDAR / mask
  ├─ 原生 FTheta → 20 个曝光中点 virtual-pinhole tile
  ├─ source-priority 动态 mask 排除动态 RGB 监督
  ├─ multi-scan LiDAR 道路深度监督 → 12k static 2DGS
  ├─ 7 相机 × 18 时间 slot → world-direction temporal sky
  ├─ 来源相机时间留出 → 6 个刚性 actor expert registry
  └─ 目标 L4 7V 直接 1920×1080 光栅化
       ├─ static 2DGS RGB/alpha
       ├─ 仅在低 alpha 后方合成 temporal sky
       └─ 视角≤25°、距离比0.60–1.60、时间窗+100 ms fade 的 actor
```

静态层采用 surface-aligned 2DGS；道路以真实 LiDAR 约束米制尺度，Depth Anything V2 仅在 LiDAR 邻域内提供低权重先验。天空 cubemap 只填透明背景，不覆盖错误高 alpha 几何。动态层只接纳来源相机时间留出达标的刚性 expert；同一 track 同一时刻至多选择一个 expert，不满足证据条件就回退静态背景。由于 static expected depth 本身可能含动态泄漏，本 final 不用它作为 actor 遮挡硬真值。

### 3.3 已测试路线与筛选结论

项目不仅验证了最终路线，也系统排除了多条“链路可跑但质量不成立”的方案。下表只列代表性结论；被拒绝路线均未进入 final。

| 路线 | 代表性实测结果 | 决策 |
|---|---|---|
| InstantNuRec 静态 PLY + dynamic NPZ | 可恢复部分近车；四帧动态改变区 MAE 改善 43.9%，但全图仅 1.68%、时序仅 0.30%，仍有多轮廓 | 仅诊断，不作最终动态层 |
| clean-static v3/v4 + canonical actor | v3 的 67 帧 ROI 改善 31.79%、全图改善 2.07%，但 temporal-delta 恶化 19.98%；v4 背景结构更干净但画质退化 | 未序列化 |
| Street Gaussians v1–v7 | v7 优于 v6，但精确四帧 MAE 0.06893，仍差于 static 0.06094；actor 与 static alpha 高重叠 | 否决生产 |
| 原生 FTheta/rolling direct actor + pose correction | 短窗可改善 ROI；67 帧时序 residual 分别恶化 30.65% 和 35.77% | 停止加 iteration/调 pose |
| SAM2 mask、raw LiDAR actor、RoMa correspondence | SAM2 仅作监督 sidecar；严格 RGB-LiDAR densification 只新增 1 点、surface observed 2.81%；两组 RoMa 几何审计 accepted 均为 0 | 证据不足，不写 actor |
| EmerNeRF native FTheta/rolling | v2 的 22 帧短窗 ROI 改善 18.30%，但后续更长窗 v3 为负；v5 visible-alpha IoU 仅 0.1015 | 不进入人员/序列/L4 |
| 11-tile → 20-tile static 2DGS | multi-scan LiDAR、近场/侧向 tile 和 12k holdout 选择改善道路轮廓与深度；仍不解决动态泄漏 | 选为 final 静态背景 |
| 刚性 actor expert registry | 6 个来源时间留出 expert 通过 RGB/轮廓/面积门槛，目标侧再按方向、距离、时间 fail-closed | 作为有限动态增强 |

这些实验共同说明：当前可交付能力主要来自静态表面、世界方向天空、连续目标位姿和保守的局部刚性 actor；动态对象完整新视角重建仍是主要瓶颈。

## 4. 指标达成情况

### 4.1 评价原则与指标定义

目标 L4 新视角没有同步实采图像，所以指标按“交付完整性—静态几何—来源 actor 留出—最终合成安全/时序代理”四层组织：

- **完成率**：存在且可解码的输出帧数 / 要求帧数。
- **道路深度 MAE**：在独立 proxy view 的原始 LiDAR 有效道路像素上计算 `mean(|d_render-d_lidar|)`；median/P90 分别描述典型误差和尾部误差。
- **来源 actor masked RGB MAE**：仅在来源相机保留时间帧的实例 mask 内计算。
- **alpha IoU / 面积比**：以预测 `alpha>0.5` 与实例 mask 比较轮廓交并比及面积比例。
- **actor 外 RGB MAE**：在最终 1080p `actor alpha≤1/255` 的像素比较合成 RGB 与同分辨率静态背景；只检查合成器是否污染 actor 外区域。
- **相邻 alpha IoU**：相邻帧 `alpha>0.5` 的 IoU，是轮廓连续性代理；目标进出视场、遮挡和 gate 切换都会降低它。

除完成率和协议一致性外，这些指标各自只覆盖明确的有效域，不能合并解释为“目标 L4 全像素真值准确率”。

### 4.2 静态道路 LiDAR holdout

静态 2DGS 使用与 final 完全相同的 iteration 12000 模型，在独立 240 个 proxy view、6,067,229 个有效道路 LiDAR 投影像素上评测：

| 有效道路像素 | MAE | median | P90 |
|---:|---:|---:|---:|
| 6,067,229 | 1.067868 m | 0.253191 m | 1.997339 m |

该结果表明模型在 LiDAR 支持的静态路面上保留了米制尺度约束；P90 同时表明近场、边缘或稀疏覆盖区仍有明显深度尾部误差。它不评价车辆、人员或 7V 全像素深度。原始证据：`evidence/road_lidar_holdout_same_static_model.json`。

## 6. 应用成效分析

### 6.1 数据复用与采集成本

同一段乘用车多传感器采集经一次静态场景资产构建后，可以替换目标 rig JSON 并批量生成七个不同安装位姿的同步视角。本次由 299 个源参考时刻生成 2,093 个目标相机时刻图，说明流程能够复用已有世界几何、轨迹、天空和部分刚性对象资产，减少早期相机布局论证、演示视频制作和算法接口联调对目标小车实车采集的依赖。

但它不能把“少采一次目标车”解释为“无需目标车验证”。真实目标镜头标定、曝光/ISP、车辆包络遮挡和目标视角动态真值仍需实车或高可信仿真补齐；当前流程降低的是方案验证与展示成本，不是安全验证成本。

### 6.2 可支撑的用途

- L4 小车七路相机安装方案和视场覆盖的可视化；
- 跨车型数据接口、时间同步、视频协议与批处理链路联调；
- 静态场景重建、道路 LiDAR 监督和 conservative actor compositing 的方法对比；
- 后续 view-dependent、visibility-aware 动态模型的统一静态背景和拒绝式基线。

### 6.3 不可直接支撑的用途

- 自动驾驶感知训练地面真值或动态对象真值标注；
- 碰撞距离测量、安全认证、闭环驾驶策略训练；
- 行人行为、遮挡关系或完整车辆表面的真实性判断；
- 宣称为 Neolix 或任一 OEM 车型的真实标定及实采相机流。

## 7. 失败案例与改进方向

当前最主要的失败不是视频封装或坐标链路，而是源观测对目标新视角的几何、外观和可见性约束不足：静态层会吸收移动对象，刚性 actor 只覆盖已观察表面，侧后向和近场放大这些问题。具体可见症状、证据、已否决修复及禁止用途见 [`失败案例与限制.md`](失败案例与限制.md)。

后续优先级为：

1. 获取至少两路有效原生 FTheta/rolling 的对象观测或目标 rig 小规模实采，用于严格跨相机/目标视角 holdout；
2. 将动态对象迁移到显式实例 occupancy、visibility、unknown surface、view-dependent appearance 与 depth ordering 的对象层，不再依赖单套刚体、单目纹理或 static expected depth；
